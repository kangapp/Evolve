# Evolve

把需求、实施、验证、项目知识和跨会话续接连接起来的单项目 AI 工作流插件。当前工程版本 **0.1.0**，支持 Codex 与 Claude Code；运行时使用 Python 3.11+ 标准库。用于本地／私有安装，尚未公开发布。

## 安装并开始

1. 从源码根构建完整包：`python3 scripts/build_package.py --out /absolute/path/evolve-installed`。输出目录须不存在，替换为自己的绝对路径；拿到完整运行包可直接放到稳定安装目录。
2. 按[安装指南](docs/installation.md)将完整目录注册到所用宿主，并只在目标项目启用。八个 Skill 共用一份 shared／runtime，不单独复制 Skill。
3. 在目标项目对 AI 说：**“使用 Evolve 看一下这个项目，先说明理解和方案，不修改业务文件。”**
4. 明确准备实施时再说：**“使用 Evolve 接入；呈现具体方案，在我已授权的范围内实施、检查和封存。”** 接入只建立工作资料，不自动批准正式知识。
5. 换会话说“继续这个工作项”。先定位真实项目与保存结果，核对当前现场和原授权；只调查、只验收等单阶段指令会保持边界。

宿主显示的 Skill 名称带 evolve 命名空间，例如 `evolve:evolve-workflow`。用户表达工作目标即可，内部编号与请求由 AI 准备；不要求存在全局 `/evolve` 命令。

## 能做什么

- 短方案的小修改，以及带 spec、依赖和独立验收条件的复杂任务。
- 独立调查、原症状复验、正常暂停与只读续接。
- SQL／数据口径调查、有限血缘底稿和从已存事实导出报告。
- 具体差异批准后的正式文档应用，多工作项协调与来源核对。
- 带适用边界的经验、反例，以及按授权转成检查或正式知识。
- 具体候选批准后的受控 SQLite 数据操作、未知核实和独立补偿；完整档案备份与恢复。

任务实施、真实检查、逐 AC 验收和封存分别记录。历史通过不等于当前现场仍通过；恢复 Evolve 档案不会回滚业务源码、数据库或外部效果。运行时实际方法与版本以只读 status 为准。
