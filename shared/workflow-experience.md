# 工作流引导、标识与交接

八个 Skill 在进入、切换和结束阶段时读取本页。动作归属以 package.py 的 OWNERS 为准，具体执行使用各分支协议。用户表达目标，Agent 准备请求并接力，用户无需填写内部编号。

## 进入与会话核对

1. 用 `[Evolve · <实际 Skill> · 开始核对]` 简短说明目标及本轮范围。此时表示已选择流程；实际启动、提交和完成按工具回执报告。
2. 从宿主给出的实际 Skill 路径定位完整插件。首次读取清单时在会话保留 content_digest，随后每次 CLI 调用传 `--session-package-digest <该摘要>`。更新后沿原会话摘要核对；SESSION_PACKAGE_MISMATCH 转新会话。重新读取文件当前摘要不能证明旧会话已加载新说明。
3. status／next／resume 使用 evolve-workflow 的 owner，其他阶段使用实际 owner。doctor 可独立诊断旧版或异常档案。
4. 阅读 readiness 分项条件及 activation。ready 只表示已观察到的执行前提，实际检查通过、宿主加载分别核实；未观察到的项目如实报告 not_observed。

## 指南与入口

用户问“怎么用”“现在该做什么”或首次描述修改目标时，由 evolve-workflow 解释并分派。只读咨询直接给结论、原因及一条可发送示例，保持项目不变。

| 现场 | 引导 |
|---|---|
| 未接入的已有代码 | 按目标读取相关规范、实现与检查，明确必要接入范围；授权留档后由 init 建记录设施 |
| 空仓库、只有想法 | 明确目标、边界、最小可验收行为与关键选择，再形成方案；知识如实描述尚无实现 |
| 已有任务 | resume 恢复准确目标、原方案、授权和当前差异，按就绪任务继续 |
| 多个目标 | 给简短候选，按标题选择，独立调查可继续 |
| 包或档案异常 | maintain.doctor 诊断；更新、恢复、修复按各自具体方案推进 |

调查深度按[实际缺口](context.md)选择。局部修改可以只建立必要记录并定向调查；完整初始化按[知识交付](project-knowledge.md)的范围完成。只询问会改变目标、范围或关键取舍的缺口。

## 阶段切换与连续推进

跨 owner 显示 `[Evolve · <原 Skill> → <接手 Skill>]`，用一句话说明实际原因和目标。只在进入、实质切换和收尾时显示，工具细节按需展开。

有效完整授权内自动推进方案、实施、检查、必要修正、知识交付、最终验收与封存。只规划、只验收、只调查或暂停请求在相应阶段结束。需要实际决定的具体内容先完整呈现；已有准确授权按原范围继续，阶段切换本身无需再确认。

方案保存、任务实施、文档验收、整体验收和封存分别报告。任务验收后继续就绪任务；业务实现通过后交付必需知识，再取得最新整体验收与封存。经验回顾保存有来源的可复用发现或核查后的无新发现。

## 结束与接手

读取回执顶层 workflow 的 marker、phase_status、stage_complete、goal_complete、remaining、next_steps、evidence。call_finished 仅代表本次 CLI 调用返回；结合本轮全部实际结果说明阶段及目标进度。候选检查、结构检查或包检查保持其实际范围。

最终回复使用统一标记，简洁说明：阶段状态、实际成果、整个目标是否完成及剩余必需项、接手 Skill 和原因、一条可直接发送的指令。无必需后续时明确说明，后续建议保持可选。Skill 名称使用宿主实际显示的名称，也可使用自然语言。

- completed：本阶段完成；只有 archive 的完整证据支持 goal_complete。
- observed：只读观察完成，原工作状态保持。
- waiting_confirmation：候选或方案需要实际具体决定；已有准确决定时沿其依据继续。
- paused：部分结果已保存，恢复原工作继续。
- blocked：保留真实失败及已发生结果，说明缺失条件、接手路径和能力限制。
- cancelled：未来执行已取消，历史及已发生效果保留。

失败时参考 error.next_steps 与 workflow.next_steps。中断沿原请求恢复；已结束但资料缺失先评估 repair。无法证明可修复时说明所需证据或插件修复事项。

## 本机暂存

写请求优先标准输入，文件回退仍使用 control/requests。需要呈现的候选可放 `.evolve-local/review/<本次工作名>/`，注明暂存副本。正式候选、决定和版本由历史记录负责，正式正文应用到登记位置。收尾说明仍保留的候选用途；只有已安全落档、无未决引用且由本次创建的暂存副本可按需清理。原始证据、未知内容和中断所需资料保留。
